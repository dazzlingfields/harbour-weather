Harbour Blend and a map that fills the screen.

- Harbour Blend is the new default. It combines ECMWF IFS, NOAA GFS and DWD ICON weather with ECMWF WAM, NOAA GFS Wave and Météo-France waves.
- Equal initial weights, robust scalar averaging and circular direction averaging. Full model ranges are retained. Supplementary water/current/visibility data stays labelled and never counts as another vote.
- Per-hour High/Medium/Low confidence and a detailed agreement index, with fewer members, disagreement and longer lead times reducing confidence. This is a heuristic, not a calibrated accuracy probability.
- Trip windows use the highest available model wind, gusts and waves and exclude low confidence hours.
- One-tap model presets, with separate weather/wave choices in an optional advanced section.
- Full-screen marine map with floating search, tools and navigation. The forecast starts as a compact strip showing wind, waves and confidence; tap or swipe its heading to expand.
- Bounded dialogs and panels, smaller cards, improved narrow-screen/landscape layouts, a fix for the file import control causing horizontal overflow, and restrained transitions that respect reduced motion.
- New cache schema and application-shell version, plus the same updated web assets bundled in Android.

Install the APK below for Android testing. Debug signing may differ between builds, so export saved marks before removing an older installation. Fresh forecasts and chart tiles require internet. Model agreement does not establish safe boating conditions; check official marine warnings and local conditions.
