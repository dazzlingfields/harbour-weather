Hourly forecasts and improved Android controls.

- Map forecast: one column per hour, weather icons above wind, gusts, direction, waves, period, swell and rain.
- Default 3-day view and optional 7-day view, with date shortcuts and expandable extra statistics.
- Wind and wave strength colours, with a colour key; missing values remain explicit.
- Switch wind/weather between Best match, ECMWF IFS, NOAA GFS and DWD ICON. Select waves separately from Best match, ECMWF WAM, NOAA GFS Wave and Météo-France Wave.
- Missing ancillary fields use labelled complementary data. Selected model values remain intact, with per-value provenance for later confidence work.
- Compact map toolbar, consistent touch controls, centred settings icon, corrected Android safe areas, system-bar styling and Back handling.
- Forecast, preferences, tides and marks remain shared between the website and bundled Android app.

The API is free for non-commercial use under Open-Meteo's terms. All model delivery currently uses Open-Meteo. No blended confidence score is generated.

**Install the APK asset below.** This is a test build with debug signing. Android may require an earlier test installation to be removed; export saved marks before doing that. Chart imagery remains reference material. Internet is required for fresh forecasts and online charts.
